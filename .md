# Descripción de la tarea

La tarea consiste en desarrollar y exponer una API utilizando Express con Node.js, o con cualquier otro lenguaje de programación que se maneje, según convenga.

Además, se debe subir el proyecto a un repositorio, compartir los enlaces de los repositorios y proporcionar las URL necesarias para consumir la API.

Como evidencia de funcionamiento, también se debe incluir una demostración de que la API responde correctamente; opcionalmente, esta prueba puede realizarse con Postman.
